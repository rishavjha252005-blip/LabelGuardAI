# 3-minute demo script

1. Run the app and open **Compare revisions**.
2. Upload `sample_approved_label.txt` as Approved label and `sample_revised_label.txt` as Revised label.
3. Show the change from `STERILE EO` to `STERILE R` and the missing `Do not re-sterilize` statement.
4. Open **Validate a label**, upload `sample_revised_label.txt`, and show checklist findings.
5. Open **Review report & impact**, download the JSON report, and explain traceability.
6. State clearly that rules are illustrative and qualified human review is required.
